    탐지 엔진 (Logic1 ~ Logic4 + AI)
    
      
    각 엔진의 역할과 탐지 방식을 요약
    
      
    
        
    Logic1 · URL/CIDR/레퓨테이션
    도메인·IP·패턴 매칭
    - WHOIS/네임서버/등록 연차 기반 신뢰도 평가
    - IDN/동형문자 탐지
    - CIDR 블랙리스트·ASN 판별
    - HSTS 정책·리다이렉션 점검
    
        
    Logic2 · 캡처 기반 탐지
    스크린샷 비교 분석
    - 캡처 후 정상 서비스와 유사도 비교
    - UI/로고/버튼 배치 기반 위장 판별
    - 이미지 해시·패턴 기반 탐지
    
        
    Logic3 · DOM/JS 정적 분석
    코드 시그니처 & 구조 분석
    - 입력 폼, 키이벤트, 클립보드 접근 탐지
    - 외부 링크, 피싱 키워드 탐지
    - 난독화 해제 후 악성 코드 비교
    
        
    Logic4 · 네트워크 로그 기반 탐지
    네트워크 트래픽 분석
    - Origin vs Host 불일치
    - TLS/SNI, JA3 지문 분석
    - 비정상 포트·빈도 탐지
    
        
    AI 분석 · LLM 기반
    코드 & 문맥 기반 의미 추론
    - LLM으로 코드 의미 분석
    - 난독화 해제 코드 문맥 이해
    - 피싱 패턴 자동 식별
